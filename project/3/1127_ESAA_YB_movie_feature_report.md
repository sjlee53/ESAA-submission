# 피처 정리 보고서

ESAA YB 미니 프로젝트(3) · 영화 관객수 예측 · **담당: 다 (피처)**

| 항목 | 내용 |
|---|---|
| 기준선 | `submission_dirpast_raw.csv` — **리더보드 1,148,127** |
| 기준 구성 | `common.py` 전처리 + 감독 과거작 실적 + CatBoost (시드 3개 평균) |
| 피처 수 | **29개** |
| 생성 스크립트 | [`feat_variants.py`](feat_variants.py) — 후보 8개를 한 번에 제출 파일로 |

**이 보고서의 규칙 세 가지.**

- **한 번에 하나만 바꾼다.** 두 개를 같이 바꾸면 어느 쪽이 효과인지 알 수 없다.
- **교차검증으로 판단하지 않는다.** 이 대회에서 CV가 두 번 다 방향을 거꾸로 알려줬다(4절).
- **test 영화의 실제 관객수를 쓰지 않는다.** 모델 입력은 물론 **후보를 고르는 데에도** 쓰지 않는다.

## 1. 지금 쓰고 있는 피처 (29개)

### (1) 원본 변수에서 그대로 — 5개

| 피처 | 원본 | 비고 |
|---|---|---|
| `time` | 상영시간 | test의 「슈퍼레이서 엔지」 2015분은 장르 중앙값 83분으로 교체 |
| `num_staff` | 스태프 수 | **0은 그대로 둔다** — 결측이 아니라 소규모 영화 신호 |
| `num_actor` | 배우 수 | |
| `dir_prev_num` | 감독 이전작 수 | |
| `dir_prev_bfnum` | 감독 이전작 평균 관객수 | **값이 부정확하다**(2절). 그래도 뺐더니 나빠져서 유지 |

### (2) 만든 변수 — 3개

| 피처 | 만든 방법 | 근거 |
|---|---|---|
| `has_prev` | `dir_prev_num > 0` | `dir_prev_bfnum` 결측 100%가 `dir_prev_num == 0`인 행. 결측이 아니라 "이전작 없음"이라는 사실이라 0으로 채우고 유무를 따로 표시 |
| `year` | 개봉일에서 연도 | |
| `month` | 개봉일에서 월 | |

### (3) 범주형 인코딩 — 17개

| 피처 | 방식 | 근거 |
|---|---|---|
| `genre_*` (12개) | 원-핫 | 범주 12개, **test에만 있는 값 0%** |
| `rat_*` (4개) | 원-핫 | 범주 4개, test에만 있는 값 0% |
| `dist_freq` (1개) | 빈도 인코딩 | 배급사는 미등장이 15%뿐이고, **이름을 몰라도 "몇 편 낸 회사인가"는 알 수 있다** |

**감독은 범주로 쓰지 않는다.** test 243편 중 **63%가 train에 없는 감독**이다. 타깃 인코딩을 넣으면 세 편 중 두 편이 전체 평균을 받게 되어 노이즈만 늘고, 실제로 CV가 1,438,083 → 1,621,260으로 12% 나빠졌다.

### (4) 감독 과거작 실적 — 4개

**이 프로젝트에서 점수를 가장 크게 움직인 피처다.** 리더보드 1,245,912 → 1,185,603 (60,309 개선).

| 피처 | 내용 |
|---|---|
| `director_past_n` | 그 감독의 **개봉일 이전** 작품 수 (train 안에서) |
| `director_past_mean` | 그 작품들의 실제 관객수 평균 (log1p) |
| `director_past_max` | 최대 (log1p) |
| `director_past_last` | 가장 최근 작품의 관객수 (log1p) |

누수가 없다. 통계의 출처는 **정답을 아는 train뿐**이고, **개봉일이 엄격히 더 이른** 작품만 본다. 교차검증에서는 학습 폴드만 source로 넘긴다.

## 2. 왜 과거작 실적을 직접 계산했나

주어진 `dir_prev_bfnum`이 **train 안의 실제 기록과 맞지 않는다.**

| 영화 | 주어진 `dir_prev_bfnum` | train에 있는 그 감독의 과거작 |
|---|---|---|
| **베테랑** (류승완) | **97,469** | 부당거래 2,723,028 / 베를린 **7,166,532** (평균 494만) |
| 군도 (윤종빈) | 719,587 | 범죄와의 전쟁 **4,720,050** |
| 명량 (김한민) | 4,781,084 | 최종병기 활 **7,482,180** |
| 우는 남자 (이정범) | 4,016,688 | **6,178,665** |

베테랑은 **50배 차이**다. 모델 입장에서 베테랑은 "감독 이전작이 10만 명도 안 든 액션 영화"라 낮게 볼 수밖에 없다.

train에도 오류가 있다. 「타부 : 금지된 사랑」의 `dir_prev_bfnum`이 **17,615,314**(명량 관객수와 사실상 같은 값)인데 정작 이 영화 관객수는 **8명**이다.

**그래도 `dir_prev_bfnum`을 빼면 안 된다.** 빼고 돌려 보니 명량 예측이 15,051,369 → 8,384,803으로 반 토막 났다. **값이 부정확해도 "대작 감독인가"라는 정보는 담고 있다.**

## 3. 버린 것과 이유

| 시도 | 결과 | 판단 근거 |
|---|---|---|
| 배급사 **표기 정규화** (`(주)NEW` = `NEW`) | CV 1,440,532 → 1,412,640 **개선** / **LB 1,202,747 → 1,245,912 악화** | 리더보드 |
| 감독 **타깃 인코딩** | CV 1,438,083 → 1,621,260 악화 | test 63% 미등장 |
| 배급사 타깃 인코딩 | CV 1,454,543 → 1,475,848 악화 | |
| `dir_prev_bfnum` 제거 | 명량 예측 반 토막 | 예측값 확인 |
| 감독 최고작 대비 비율을 타깃으로 | 더 나빠짐 | |
| 흥행작 배수 보정 (예측 ≥ 100만 × 1.2) | LB 1,148,127 → 1,142,462 | **폐기** — 배수를 test 실제 관객수를 아는 9편으로 골랐다. 평가 데이터 오염 |

마지막 줄이 중요하다. **점수는 좋아졌지만 그 숫자를 평가 데이터를 보고 정했으므로 쓸 수 없다.**

## 4. 교차검증을 믿지 않는 이유

같은 두 항목에서 CV와 리더보드가 **정반대**로 나왔다.

| 변경 | 교차검증 | 리더보드 |
|---|---|---|
| 배급사 표기 정규화 | 좋아진다 (−27,892) | **나빠진다 (+43,164)** |
| 감독 과거작 실적 | 나빠진다 (+35,639) | **좋아진다 (−60,309)** |

원인은 분명하다. **train 600편의 교차검증에서 상위 5%는 train 안의 흥행작 30편**이고, 리더보드 점수를 좌우하는 것은 **test 안의 다른 흥행작들**이다. 오차 제곱합의 61.8%를 상위 10편이 만드는 구조에서, 600편 표본의 CV는 그 몇 편을 대표하지 못한다.

**그래서 CV는 참고값으로만 적고, 판단은 리더보드로 한다.**

보조 지표로 **최대 예측값**을 같이 본다. RMSE는 큰 값에서 제곱으로 벌어지므로, 예측 상한을 크게 낮추는 변경은 위험하다.

## 5. 후보 8개

모두 기준선에서 **한 가지만** 바꾼 것이다. `python feat_variants.py F7 F1` 처럼 일부만 다시 만들 수 있다.

| | 변경 | 가설 | 피처 수 | 참고 CV | 최대 예측 |
|---|---|---|---|---|---|
| **F0** | 기준선 | 1,148,127이 재현되는지 확인용 | 29 | 1,448,216 | 15,051,369 |
| **F1** | 직전작 하나만 (`mean`·`max` 제거) | 평균이 최신 실적을 눌러 버린다. 베테랑의 직전작은 717만인데 평균은 494만 | 27 | 1,461,797 | 13,730,042 |
| F2 | + 최근 3년 과거작 | 10년 전 흥행은 지금과 무관할 수 있다 | 33 | 1,471,444 | 8,293,044 |
| F3 | + 같은 장르 과거작 | 멜로를 찍던 감독의 액션은 다를 수 있다 | 33 | 1,466,050 | 9,239,123 |
| F4 | + 배급사 과거작 | 감독에서 통한 방식을 배급사에 적용 | 33 | 1,524,065 | 8,136,418 |
| **F5** | + 개봉 분기·요일·성수기 | 여름·겨울 성수기와 금요일 개봉 관행 | 32 | 1,465,944 | 13,423,494 |
| F6 | + 장르 × 등급 교차 | "청소년 관람불가 액션"과 "전체 관람가 액션"은 다르다 | 67 | 1,488,880 | 8,752,776 |
| **F7** | + 규모 비율 (스태프/배우, 스태프/분, log 스태프) | 스태프 수 하나로는 대작과 흥행 실패작을 못 가른다 | 32 | **1,435,719** | 13,713,710 |

### 올리는 순서

**F7 → F1 → F5**를 먼저 권한다.

- **F7**은 CV에서 유일하게 기준선보다 좋고(1,435,719), **지금까지의 가장 큰 한계를 정면으로 겨냥한다.** train에서 `num_staff ≥ 500`인 23편의 관객수가 317,505 ~ 14,262,766으로 흩어져 있어서 규모는 알아도 흥행은 모른다. 비율로 쪼개면 갈릴 여지가 있다.
- **F1**은 베테랑 같은 경우를 노린다.
- **F5**는 값이 싸고 그럴듯하다.
- **F0**은 재현 확인용이라 한 번은 올려야 한다. 1,148,127이 안 나오면 그 자체가 문제 신호다.

**F2·F3·F4·F6은 뒤로 미룬다.** 네 개 모두 최대 예측값이 830만~920만으로 떨어졌다. 상한을 낮추는 쪽이라 RMSE에 불리할 가능성이 크다.

## 7. 아직 안 해 본 것

- **과거작 실적의 가중 평균** — 최근작에 더 큰 가중치. F1(직전작만)과 F0(단순 평균)의 중간
- **감독이 아니라 배급사 + 장르 조합의 과거 실적**
- **개봉 시기의 경쟁 강도** — 같은 달에 개봉한 다른 영화의 수나 규모. train에서 만들 수 있다
- **`num_staff`의 순위(rank)** — 절댓값 대신 그해 상위 몇 %인지

마지막 항목은 `year`가 이미 있어서 효과가 겹칠 수 있다.
